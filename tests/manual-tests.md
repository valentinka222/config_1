# Ручные тестовые сценарии — Этап 1

Автоматических тестов на этом этапе нет, поэтому здесь зафиксированы сценарии ручной проверки.

| № | Ввод | Ожидаемый вывод |
|---|------|------------------|
| 1 | `ls` | `ls` |
| 2 | `cd "My Documents"` | `Команда cd вызвана с аргументами [My Documents]` |
| 3 | `unknown` | `Имя 'unknown' не распознано как имя командлета, функции, файла сценария или выполняемой программы.` |
| 4 | (пустая строка) | приглашение выводится заново, ничего не исполняется |
| 5 | `cd "New York" "LA"` | `Команда cd вызвана с аргументами [New York, LA]` |
| 6 | `exit` | `Выполняется выход из программы...`, программа завершается |
