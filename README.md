# Эмулятор командной строки

Эмулятор языка оболочки UNIX-подобной ОС. Реализует интерфейс командной строки (CLI),
максимально похожий на работу в реальном терминале.

## Статус

Этап 1: REPL - минимальный прототип с базовым диалогом с пользователем.

Этап 2: конфигурация - параметры командной строки, отладочный вывод, выполнения стартового скрипта.

## Сборка и запуск

```bash
# Сборка и запуск без параметров
./run.sh
# или на Windows
run.bat
```

Параметры командной строки
- `--vfs-path <путь>` - путь к физическому расположению VFS.
- `--script <путь>` - путь к стартовому скрипту.

```bash
java -cp out Main --vfs-path path/to/vfs.xml --script path/to/script.txt
```
## Реализовано

- Приглашение к вводу в формате `username@hostname:~$`, формируется на основе
  реальных данных операционной системы.
- Парсер аргументов командной строки с поддержкой значений в кавычках.
- Команды-заглушки `ls` и `cd`, выводящие свое имя и переданные аргументы.
- Команда `exit` для завершения работы эмулятора.
- Параметры командной строки `--vfs-path` и `--script`, отладочный вывод заданных параметров.
- Выполнение стартового скрипта: команды выполняются последовательно, ошибочные команды пропускаются.

## Примеры работы

```
user@host:~$ ls
ls
user@host:~$ cd "My Documents"
Команда cd вызвана с аргументами [My Documents]
user@host:~$ unknown
Имя 'unknown' не распознано как имя командлета, функции, файла сценария или выполняемой программы.
user@host:~$ exit
Выполняется выход из программы...
```
