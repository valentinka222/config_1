# Эмулятор командной строки

Эмулятор языка оболочки UNIX-подобной ОС. Реализует интерфейс командной строки (CLI),
максимально похожий на работу в реальном терминале.

## Статус

Этап 1: REPL - минимальный прототип с базовым диалогом с пользователем.

Этап 2: конфигурация - параметры командной строки, отладочный вывод, выполнения стартового скрипта.

Этап 3: VFS - загрузка виртуальной файловой системы из XML файла, дерево хранится только в памяти.

Этап 4: основные команды - реальная логика ls и cd по дереву VFS, команды pwd и clear.

Этап 5: дополнительная команда - chown для смены владельца папки/файла в памяти.

## Сборка и запуск

```bash
# Сборка и запуск без параметров
./run.sh
# или на Windows
run.bat
```

Параметры командной строки
- `--vfs-path <путь>` - путь к физическому расположению VFS.
- `--script <путь>` - путь к стартовому скрипту.

```bash
java -cp out Main --vfs-path path/to/vfs.xml --script path/to/script.txt
```
## Реализовано

- Приглашение к вводу в формате `username@hostname:~$`, формируется на основе
  реальных данных операционной системы.
- Парсер аргументов командной строки с поддержкой значений в кавычках.
- Команда `exit` для завершения работы эмулятора.
- Параметры командной строки `--vfs-path` и `--script`, отладочный вывод заданных параметров.
- Выполнение стартового скрипта: команды выполняются последовательно, ошибочные команды пропускаются.
- Загрузка VFS из XML файла по пути `--vfs-path`: строится дерево объектов в памяти.
- Все операции с VFS производятся только в памяти, исходный файл не меняется.
- Обработка ошибок загрузки VFS.
- Команда `cd` перемещается по дереву VFS: переход в подпапку по имени, `cd ..` для подъема на уровень повыше,
`cd` без аргументов - возврат в корень
- Команда `ls` выводит содержимое текущей папки VFS.
- Команда `pwd` выводит текущий путь внутри VFS от корня.
- Команда `clear` очищает экран терминала.
- Команда `chown` меняет владельца файла/папки в текущей директории VFS.

## Примеры работы

```
user@host:~$ ls
ls
user@host:~$ cd "My Documents"
Команда cd вызвана с аргументами [My Documents]
user@host:~$ unknown
Имя 'unknown' не распознано как имя командлета, функции, файла сценария или выполняемой программы.
user@host:~$ exit
Выполняется выход из программы...
```
Загрузка VFS при запуске:
```
Параметры запуска:
Путь к VFS: tests/vfs-samples/nested.xml
Путь к стартовому скрипту не задан
VFS успешно загружена:
root
  Documents
    Projects
      config1
        Main.java
    readme.txt
user@host:~$
```
Навигация по VFS:
```
user@host:~$ ls
Documents/
user@host:~$ cd Documents
user@host:~$ pwd
/root/Documents
user@host:~$ ls
Projects/
readme.txt
user@host:~$ cd papka
Папка papka не найдена
user@host:~$ cd ..
user@host:~$ pwd
/root
```
Смена владельца:
```
user@host:~$ chown ivan readme.txt
Владелец readme.txt изменен на ivan
user@host:~$ chown ivan notexist.txt
Файл или папка notexist.txt не найдена
user@host:~$ chown ivan
Неверный синтаксис команды
```
